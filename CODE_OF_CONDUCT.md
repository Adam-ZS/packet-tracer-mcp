# Code of conduct

Help people learn and build. Treat contributors and users with respect,
including people with different backgrounds and levels of experience.

Welcome questions, give specific feedback and discuss technical ideas without
personal attacks. Respect privacy and do not publish another person's
credentials, submissions or personal information.

Harassment, threats, discriminatory language, sexual harassment and repeated
disruptive behavior are not accepted. Maintainers may edit or remove content,
close discussions or restrict participation to protect the community. They
will consider context and apply proportionate responses.

Report a concern privately using the maintainer's GitHub profile contact
options or a private GitHub security report if the concern involves exposed
data or a vulnerability. Do not post sensitive details in a public issue.
Maintainers should handle reports discreetly and without retaliation.
